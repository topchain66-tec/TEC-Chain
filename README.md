# TEC-CHAIN

A simple blockchain implementation in Go featuring hybrid NPoS + PoW consensus, mempool, and JSON-RPC interface.

## Features
- NPoS + PoW Hybrid Consensus
- Transaction Mempool
- HTTP JSON-RPC API
- Tron-style addresses (starting with "TEC")
- High precision token system

## Quick Start

```bash
go mod tidy
go run main.go
